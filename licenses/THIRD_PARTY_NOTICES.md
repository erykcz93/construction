## Original assets created for this template

The following were created specifically for this template and contain **no third-party material**:

- All SVG icons in `assets/icons/` (drawn from scratch on a 24 × 24 grid).
- The logo mark and favicons in `assets/images/logo/` and `assets/images/favicon/`.
- All illustrations and placeholders in `assets/images/` (hero, about, services, projects, gallery, team, blog, map, 404 and decorative drawings).
- The Open Graph image `assets/images/social/og-image.jpg`, rendered from the template's own artwork. It contains no text and no third-party fonts.
- All HTML, CSS, JavaScript and PHP code.

## Names used as plain text

The footer contains plain-text links labelled "LinkedIn", "Instagram" and "Facebook". These names identify the services the links point to. No logos or trademarks of these services are included. Replace or remove these links to match your own profiles.

## Demo content

All company names, persons, testimonials, statistics and project descriptions included in this template are fictional demo content and should be replaced by the end user. Phone numbers use the 555-01XX range reserved for fictional use. Email addresses and URLs use the reserved `example.com` domain.

## Tools not included in the package

No build tools, package managers or libraries are required to use or edit the template, and none are included.
